# Wiki drafts — to be reviewed + seeded

Each `*.json` file in this folder is a draft `wiki_pages` entry ready to
POST to `/api/admin/wiki`. They were generated by a previous session
with plausible-but-unverified content.

**A human (or future session) must verify each fact** before publishing —
especially numbers (prices, interest rates, percentages, durations) and
policy statements that could create legal/marketing liability.

## How to seed all (after verification)

```bash
cd data/wiki-drafts
for f in *.json; do
  echo "→ $f"
  curl -s -X POST http://localhost:3800/api/admin/wiki \
    -H "Content-Type: application/json" \
    --data @"$f" | python3 -c "import json,sys; d=json.load(sys.stdin); print('  ok:', d.get('page',{}).get('slug')) if 'page' in d else print('  ERR:', d)"
done
```

Or use `seed.sh` (same loop, executable).

## Format

```jsonc
{
  "slug": "kebab-slug",          // unique, URL-safe
  "title": "หัวข้อภาษาไทย",
  "kind": "policy" | "faq" | "process" | "product" | "brand" | "note",
  "bodyMd": "## หัวข้อ\n\nเนื้อ markdown\n\nรองรับ [[wikilink]] ลิงก์ไปหน้าอื่น",
  "tags": ["..."],
  "aliases": ["..."]              // คำที่ลูกค้าอาจใช้เรียก
}
```

## ปัจจัยที่ส่งผลต่อ bot accuracy

- ใส่ **FAQ inline** ในตอนท้าย body — "ลูกค้าถาม X → ตอบ Y" — bot ใช้ pattern นี้หาคำตอบเร็ว
- `aliases` ต้องครอบคลุมศัพท์ลูกค้าใช้จริง เช่น "ดาวน์" / "เงินดาวน์" / "วางดาวน์"
- รุ่นรถใน wiki ต้องตรงกับ `car_models` table (slug จะ match กัน auto)
